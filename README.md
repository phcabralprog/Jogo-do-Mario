# JogoMario

## Descrição

Um pequeno jogo de mario no estilo do Chrome Dino, em que o mario fica pulando obstaculos (canos) infinitamente

## Tecnologias

-HTML
-CSS
-JAVASCRIPT

## Instalação

cd frontend
npm install

## Execução

npm run dev
